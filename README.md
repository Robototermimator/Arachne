# 🕷️ Arachne

### Wearable Computer Vision & Situational Awareness

Arachne is a Python-based computer vision prototype inspired by the concept of an intelligent wearable suit.

The project explores how computer vision can transform a camera feed into real-time situational awareness by detecting, tracking, analysing, and predicting target movement.

## Current Capabilities

- Real-time camera processing
- HUD interface
- Motion detection
- Target acquisition
- Target locking
- Target tracking
- Position smoothing
- Direction detection
- Speed estimation
- Acceleration/deceleration detection
- Movement classification
- Relative distance estimation
- Distance trend analysis
- Movement trail
- Velocity vector
- Target persistence
- Short-term movement prediction
- Prediction confidence
- Target-loss handling

## Technology

- Python
- OpenCV
- PyTorch
- Ultralytics YOLO11n

## YOLO Status

YOLO11n has been integrated into the project and successfully tested for inference.

Object recognition is **not yet active in the live Arachne pipeline**.

The next development stage is asynchronous YOLO inference and integration with the target-tracking system.
